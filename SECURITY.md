# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report them privately through GitHub's [private vulnerability reporting](https://github.com/pagework-dev/pagework/security/advisories/new). Include what you found, how to reproduce it, and what an attacker could do with it.

You should get a first reply within seven days. Fixes for confirmed issues are released before details are published, and reporters are credited unless they ask not to be.

## Supported versions

There are no releases yet. Once there are, the latest minor release receives security fixes.

## Scope

In scope: the Pagework server, web app, Docker image and anything in this repository.

Out of scope: vulnerabilities in a third-party dependency that are already public (report those upstream), and problems that need an attacker to already control the server.

## Things worth knowing

Scripts are unproduced creative work and are treated as sensitive data. Bugs that let one user read or change another user's or organisation's scripts are the most serious class of issue in this project.
